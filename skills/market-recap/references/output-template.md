# 复盘输出模板

按顺序写；空节用「—」占位，不要删节号。

```markdown
# {YYYY-MM-DD} {今日|午盘|早盘|周末}复盘

时间：...  
模式：一句话结论 → 指数与量能 → 情绪温度 → 主线拆解 → 持仓复盘 → 次日计划

> **持仓组**：（若有）代码 / 名称

## 1. 一句话结论
用 2–4 句概括：指数结构 + 情绪 + 主线 + 持仓含义 + 次日焦点。

## 2. 指数与量能
| 指数 | 收盘 | 涨跌幅 |
量能特征 / 关键信号（3 条内）

## 3. 情绪温度
| 指标 | 数值 | 对比昨日 |
宽度定性一句话（赚钱效应在哪、亏钱效应在哪）

## 4. 主线拆解
### 主线 A / B / C（含代表股表格 + 催化）
### 明确偏弱

## 5. 持仓复盘
（无持仓则写「未提供持仓」）
整体表 + 分票量价/逻辑/风险 + 结构评价表

## 6. 次日计划
日历催化 · 情景 A/B/C · 纪律 · 关键位速查表

## 7. 数据口径
| 数据项 | 来源 |
免责声明
```

范例见归档：`docs/market-recaps/2026-07-26_今日复盘.md`。
