## 4. 主线拆解

### 强势方向

- 存储芯片 / 半导体：大普微 20CM，生益科技、深科技等强势，属于今天最清晰的进攻方向之一。
- CPO / 光通信：华工科技反包涨停，华盛昌 3 天 2 板，说明 AI 硬件链没有退场，只是从全面扩散切回核心辨识度。
- 机器人 / 机器视觉：北自科技 3 连板，华培动力、华达科技、索辰科技等跟随，活跃度仍在。
- 油气：受事件驱动全天偏强，中油工程涨停，更多像独立催化。
- 电信 / Token 经营：三大运营商午后异动，属于新催化带来的资金试探。

### 弱势方向

- 体育概念：集体走弱，属于当天最明显的杀跌板块之一。
- 工程机械、汽车整车、贵金属等：整体承压，说明资金风险偏好并不均衡。

### 盘面核心判断

今天的主线没有彻底散，但已经从“大科技全面进攻”切成了“科技内部轮动，资金抱核心”。  
换句话说，主线还在，难度变高了。

1. 看成交额能不能重新回到 3 万亿上方。
2. 看科技线能不能继续围绕存储、CPO、电信算力抱团。
3. 看华工科技、深科技、兆易创新、中天科技这类辨识度票，能不能继续给强反馈。

### 再看持仓

1. 天孚通信：看承接，不看嘴硬。
2. 光库科技：看强度延续，能强才有继续做核心的资格。
3. 东阳光：看有没有二次放量确认，而不是只看消息想象力。

### 节奏原则

- 缩量日不追后排。
- 只围着主线辨识度做判断。
- 弱板块不给机会时，不去硬找理由。
